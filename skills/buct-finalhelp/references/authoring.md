# 资料分析、题型与评分

`analysis.md` 至少包含实际读取范围、无法确认的页/图/公式、知识点—出处—题型—覆盖题目 ID 的映射。不要根据课程标题猜测考试重点；区分“原文强调”“用户指定”“出题建议”。保留原文术语、符号、公式、单位及适用范围。

| 资料中的知识 | 适合题型 | 设计要点 |
| --- | --- | --- |
| 定义、组成、术语、公式符号 | 填空、选择 | 每空独立接受同义词；有序答案不随意交换 |
| 概念边界、适用条件、常见混淆 | 判断、选择 | 一题只检验一个清楚命题，解析指出错误条件 |
| 原理、差异、因果、优缺点 | 简答 | 分点评分，允许等价表述；否定和矛盾需语义判断 |
| 公式应用、量纲、数据处理 | 计算 | 数据充分，写明单位和精度，独立复算，区分结果分和步骤分 |

不强制每个知识点覆盖五种题。用户要求固定数量/比例时，记录各题型计数，不能生成后以“尽量”代替约束。对无法忠实出题的内容说明原因。

每题解析回答：正确答案是什么、依据是什么、为何错或漏分、资料在哪里。不要在题干或选项中泄露答案。无唯一答案时明确多选或多种可接受答案。复用原题时标明来源；示例和生成题不冒充历年真题。

默认每题可多次练习。答过才显示参考答案，错答后允许修改。顶部已完成为当前有评分的题目数，当前答对仅含确认满分；历史错题为曾被确认扣分的题目并保持记录。规则初评不进入确认错题或确认答对统计。
