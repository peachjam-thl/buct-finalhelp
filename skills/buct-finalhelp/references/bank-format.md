# 固定答案题库 v2

仓库中的 `examples/demo-bank.json` 是完整示例。题目、答案、解析均由调用 Skill 的同一个 AI 预先写好，由 AI 将题库直接嵌入专属页面；学生打开即可练习，不手工导入题库。页面呈现内容并保存核对、自评和错题，不在答题时生成答案。

顶层：`version:2`、`id`、`title`、`sources`、`questions`；可选 `subtitle`、`author`。`author` 如实标记出题者；不知道确切模型名称时用“当前出题 AI”，无需选择模型。

来源：`id`、`title`、`locator`、`excerpt`，均为非空字符串。位置真实可复查，摘录支持题目。无用户资料时示例必须写明为自编材料。

每题必填：

- 唯一 `id`（字母/数字开头，后接字母、数字、短横线或下划线）、`type`、`chapter`、`knowledge` 非空列表。
- `difficulty` 为基础/进阶/综合，`prompt` 题干，`source_ids` 关联有效资料。
- `answer` 为题型对应的固定答案，`explanation` 为完整解释。
- `solution_steps` 为至少一项的必要解题步骤；`checkpoints` 为至少一项自查要点；`common_mistakes` 为至少一项具体易错点。全部是字符串列表，不带分值。

## 公式排版

题干、选项、固定答案、解析、步骤和来源摘录都支持 KaTeX 数学排版。行内公式用 `\(...\)`，独立公式用 `\[...\]`，也兼容 `$...$` 与 `$$...$$`。使用 `\frac{a}{b}`、`\int_{0}^{\infty}`、`e^{-4t}`、`\sqrt{x}`、`\times10^{-3}`、矩阵等规范表示。

在实际 JSON 字符串中，反斜杠必须转义，例如：

```json
{"answer":"\\[E=\\int_{0}^{\\infty}e^{-4t}\\,\\mathrm{d}t=\\frac{1}{4}\\]"}
```

网页只对公式片段排版，普通内容作为文字显示，不接受任意 HTML。完整 LaTeX 文档、外部图片命令和自定义宏包不在支持范围；命令不受支持或括号缺失时提供具体字段位置供原 AI 修正。对于用户示例形式 `E=∫₀^∞ e^(-4t)dt=1/4`，页面包含一个有限的无损显示转换；其余旧式公式应由原 AI 规范为有明确边界的 LaTeX，不尝试猜测或计算新答案。

填空答案数组用于实际核对，保持学生可以输入的普通写法，例如 `[["1/4","0.25"]]`。如需漂亮的分数展示，可另加 `answer_display:["\\(\\frac{1}{4}\\)"]`，数量须逐空对应。展示格式不会改变可接受答案。

| type | answer | 其他字段 |
| --- | --- | --- |
| choice | 选项 ID 列表，如 `["A"]` | `options:[{id,text},…]`，`multiple:true/false`；按选项集合完全匹配，多选漏选/多选均为错 |
| fill | 逐空答案及等价表述，如 `[["敏感元件"],["转换元件"]]` | 每空匹配给定答案或别名；任何一空错误会自动加入错题 |
| boolean | 布尔值 `true/false` | 按预设真假自动核对；字符串 `"false"` 不是布尔值 |
| short | 完整参考答案字符串 | 步骤和自查要点覆盖关键结论，不只列关键词 |
| calculation | 包含数值和单位的固定答案字符串，如 `"I=2 A"` | 步骤明确公式、代入、运算、结果及单位；允许说明等价解法 |

不设置 `points`、`score`、`rubric`、`keywords` 等评分配置。只有选择、填空、判断按给定答案自动判对错，不计算数值分数；简答和计算继续自行对照。填空仅去首尾空格、做 NFC 规范化并把全角 ASCII 转为半角，大小写、内部空格与符号仍有意义；需要接受的变体应由原 AI 列入答案数组。页面不执行学生表达式，不请求任何模型服务。

## 追加与进度

由出题 AI 合并新旧题目、核查重复题和 ID 冲突，然后重新构建完整专属页；追加要求相同课程 `id`，来源 ID 对应内容一致。同题目 ID 内容变化应是有意修订，不能误覆盖其他题。不要让学生上传或粘贴题库来完成追加。

进度 v5 以课程 ID 和每道题（含其引用来源）的内容指纹关联。追加题目不重置旧题；只重置内容或依据发生变更的题。保存草稿、解析状态、客观核对、主观自评与历史错题，不含分数。仍能读取整库指纹完全相同的旧 v3/v4 记录。修改课程 `id` 会被视为另一门课程。
